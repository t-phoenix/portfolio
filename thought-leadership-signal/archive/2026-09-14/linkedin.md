## Post

99.9% and 62.7% are the same model.

ARC Prize ran GPT-6 Astra on ARC-AGI-3 under two harnesses. Under OpenAI’s Provider Adapter the score printed 99.9%. Under ARC Prize’s own standard harness it printed 62.7%.

A harness is the software around the model. It decides which tools are available, what state persists between requests, and how context gets compacted. Same weights. Different system. Different number.

One row should make product people pause. Inside the adapter, with reasoning effort set to none, Astra still scored 96.7%. That beat the same model at maximum reasoning inside the standard harness. The scaffold moved the result more than the dial that sounds like intelligence.

The number that travelled through feeds was 99.9% against an older model’s 7.8%. Those were not aligned setups. The like for like comparison ARC Prize supports is 62.7% versus 7.8%. Still an enormous jump. Not the AGI poster. ARC Prize said plainly it is not claiming AGI.

Then the footnotes moved. Fortune compared archived snapshots of OpenAI’s launch post and found multiple metrics revised after publication. That is a different kind of product risk: not only capability, but whether the receipt stays still long enough to trust.

I keep returning to one buying rule.

Benchmarks increasingly measure assembled systems. The thing that scored 99.9% is a harness plus a model. The thing on many price lists is sold as a model.

When you buy a model, do you evaluate weights alone, or the full harness you will actually run in production?
