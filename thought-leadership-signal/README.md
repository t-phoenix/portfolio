# Thought Leadership Signal

Personal brand thought leadership system for X and LinkedIn.

**Short mark:** Signal  
**Folder:** `thought-leadership-signal/`  
**Cadence:** 1 post per day on both platforms  
**Output:** publish ready copy packs  
**Budget:** $10 / month AgentCash  
**Positioning:** Web3 x AI builder / CTO

## Navigate

| Path | Purpose |
|------|---------|
| [`brand/`](brand/) | Guidelines, voice, engagement doctrine, creative playbook, real asset library |
| [`topics/TOPICS.yml`](topics/TOPICS.yml) | Pillars, keywords, AgentCash query packs |
| [`topics/SELECTION.md`](topics/SELECTION.md) | How to pick: Web3 / AI / intersection; no sequel theses |
| [`research/`](research/) | News, social, trends with sourced facts |
| [`queue/`](queue/) | Publish ready packs |
| [`archive/`](archive/) | Posted packs |
| [`ops/`](ops/) | Pipeline, budget, AgentCash, publish scheduler, templates |
| [`ops/LEARNINGS.md`](ops/LEARNINGS.md) | Session learnings (X OAuth, costs, dry-run traps, thesis arc) |

## Non negotiables

1. **Million dollar creative bar** — studio craft, not AI sludge. See [`brand/CREATIVE_PLAYBOOK.md`](brand/CREATIVE_PLAYBOOK.md).
2. **Real world assets only** — photography, logos, memes, NFTs, screenshots, charts from real data. See [`brand/ASSETS.md`](brand/ASSETS.md).
3. **Long term value** — teach, connect, compound. No engagement farming. See [`brand/ENGAGEMENT.md`](brand/ENGAGEMENT.md).
4. **Sourced reality** — every pack ties to news, discourse, or lived builder story with citations in research.

## Daily flow

3. Build `queue/YYYY-MM-DD/`
