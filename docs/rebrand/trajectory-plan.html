Mission AA-1:
from a 2002 PC to $2B onchain

A rebrand of abhinil.in built on four of Scrolltide's eight free themes. The whole site becomes one scroll: a launch from Earth to the Moon, with each existing section as a stage of the flight. All content in src/data, every section anchor and the Potshot game logic stay as they are. Only the presentation changes.

Spine: SELENE Hero: Aurora Type + proof: Fluxora Potshot: Otis + Monsoon Projects: Visor Contact: Glacier

Source

The 8 free Scrolltide themes

Scrolltide (scrolltide.co) sells scroll-driven templates as prompts you paste into Claude, Cursor or v0. 8 of its 156 templates are free, with personal and client use allowed. These prompts give direction only. We rebuild each effect with the stack the site already has (React 19, Framer Motion, GSAP, Lenis, tsParticles), so no Scrolltide code ships. Fonts and colours below are inferred from the template pages, which publish no specs.

Implementation plan

From branch to production

The work happens on one branch, rebrand/trajectory, with one commit per phase and one commit per section in P3, so any single section can be reverted. Production does not change until the Vercel preview passes every gate and you sign off.

  1. Safety net, before touching any styles

    • Branch from main. Run pnpm build and pnpm lint and record the current result as the baseline
    • Add @playwright/test as a dev dependency (the repo has no tests yet). Capture baseline screenshots of production at 375 and 1440 wide
    • Content-parity test: import every file in src/data and assert each company, project, tool, blog title and achievement name renders on the page. This is the guard that the data survives
    • Record Potshot read values (pot, paid out, plays) from BaseScan for later comparison

    parity test passes on the current site

  2. Tokens and fonts

    • Add the new colour tokens and 3 font families to @theme in src/index.css. Alias old names (--color-primary → space ink, and so on) so nothing breaks
    • tailwind.config.js duplicates the theme but Tailwind v4 reads @theme. Confirm it is unused, then delete it

    build passes, site looks the same apart from colour and fonts

  3. Global shell and new assets

    • Starfield options, altitude progress, nav renames, AA-1 patch, AuroraBackdrop, horizon SVG and Earthrise SVG
    • Self-host the portrait. Make the OG image and favicon

    reduced-motion pass: nothing animates when the setting is on

  4. Sections, one commit each

    • In this order: Hero → Contact/Footer (the story's two ends first) → Experience → Projects → Tools → Blog → Achievements
    • Each commit touches only its own component file plus any new child component. Data files stay untouched

    parity test green after every commit

  5. Potshot skin

    • PipMascot, odds bar, pressure meter, label changes and the inline status line in place of alert()
    • CI step: git diff --exit-code main -- src/components/potshot/hooks src/components/potshot/helper src/config

    hooks, helper and config diff is empty; preview reads match BaseScan

  6. Full test pass on the Vercel preview

    • Automated: build, lint, parity test, unit asserts, and Playwright visual review at 375, 768 and 1440 (reviewed by eye, since the layout changes on purpose)
    • Performance: mobile Lighthouse with LCP and CLS no worse than the P0 baseline, and JS bundle growth under 15%
    • Accessibility: axe with no serious issues, keyboard through nav, project fan, Potshot and form
    • Devices: iOS Safari and Android Chrome on real phones (sticky pinning plus Lenis is the usual failure)
    • Functional: all 7 nav anchors, EmailJS delivery, wallet connect, chain switch, ticket flow to signature, and your one $1 ticket

    you approve the preview URL

  7. Ship and watch

    • Merge to main. Vercel deploys. Smoke-test production with the same checklist, minus the ticket
    • Rollback: Vercel instant rollback to the previous deployment, then git revert the merge
    • Watch Vercel Analytics for a week: scroll depth (already tracked) and Potshot section views against the prior week
